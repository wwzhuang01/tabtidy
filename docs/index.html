核心能力

把 Tab Wrangler 与 Clutter Free 的优点融进一个干净侧边栏

不再在丑陋的平铺列表里翻找网页，也不再因为忘记关标签页被迫强杀 Chrome。

🏷️

原生分组名称与配色

完整读取 Chrome Tab Groups 的组名与 9 种官方配色，配合同色左侧竖条和一键「全部展开 / 全部收起」，多窗口也能一眼定位。

⚡

跨窗口搜索与一键跳转

按标题、网址或分组名实时过滤所有窗口中的标签页；点击条目同时激活标签并拉起对应 Chrome 窗口。

✨

智能重复检测与去重

默认忽略 # 锚点与末尾斜杠，优先保留活跃、固定、锁定或已分组的页面；支持一键去重及可选的新标签自动拦截跳转。

🌙

双轨独立自动休眠与关闭

普通标签页与分组标签页分别配置休眠与关闭时长。休眠即时释放内存且保留在原分组，彻底告别 OOM 崩溃。

♻️

带分组记忆的回收站

自动收起、去重和手动关闭的标签都会记下原分组名称和颜色（最多 500 条），点击恢复自动归回原分组。

🔒

零构建、零依赖、100% 本地

纯原生 Manifest V3 ES Modules 实现，无任何网络请求与第三方脚本，适合日常与企业内网环境安心使用。

分级省内存策略

重要分组稳稳留着，临时散页自动清理

基于 Manifest V3 chrome.alarms 每分钟轻量巡检一次，所有时长均可在设置中自由调整。

普通（未分组）标签页

适合随手点开的临时资料，先休眠省内存，久未访问自动收进回收站。

15 min
自动休眠释放内存（设为 0 可关闭）
→
60 min
自动关闭并保存至回收站

分组（Group 内）标签页

持续任务优先保结构：先温和休眠，长期不用再收起（或开启「仅休眠」）。

30 min
自动休眠，标签仍留在原分组
→
24 h
收起并记住原分组（或设为仅休眠）

安装与使用

无需编译构建，3 步直接加载到 Chrome

支持 Chrome 116 及以上版本，克隆目录后直接作为已解压扩展加载即可。

1

获取扩展目录

克隆 GitHub 仓库到本地，目录内已是完整的 Manifest V3 扩展，无需 npm install 或打包。

2

加载已解压扩展

打开 chrome://extensions，开启右上角「开发者模式」，点击「加载已解压的扩展程序」并选择 tabtidy 目录。

3

一键呼出侧边栏

点击工具栏 TabTidy 图标，或按 ⌘⇧E / Ctrl+Shift+E 呼出。侧边栏内按 / 快速搜索。

权限 用途说明
tabs 读取各窗口已开标签页、点击跨窗口切换聚焦、休眠释放内存及关闭重复/超时页。
tabGroups 读取 Chrome 原生标签分组名称、颜色与折叠状态，恢复回收站页面时归回原分组。
storage 在本地 Chrome 配置文件中保存设置、最后访问时间与本地回收站历史。
alarms 按 Manifest V3 规范每分钟触发一次轻量闲置巡检，不常驻后台耗电。
sidePanel 在 Chrome 原生侧边栏中呈现 TabTidy 界面。
